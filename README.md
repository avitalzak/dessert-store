# Dessert Store 🍰

Full Stack dessert ordering system.

## About The Project

A full-stack dessert ordering system that allows users to build custom desserts by selecting a base, toppings, and syrups, manage a shopping cart, and place orders.


## Technologies

### Client
- React
- Vite
- Redux Toolkit
- React Router

### Server
- Node.js
- Express
- MongoDB
- Mongoose
- JWT Authentication

## Features

- Build custom desserts
- Shopping cart management
- User authentication
- Favorites management
- Order management
- Admin dashboard
- Image upload with Cloudinary


## Running the Project

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
node app.js
```

# Dessert Store 🍰

Full Stack dessert ordering system.

## About The Project

מערכת להזמנת קינוחים המאפשרת למשתמש לבחור בסיס קינוח, להוסיף תוספות וסירופים, לנהל עגלת קניות ולבצע הזמנות.

## Technologies

### Client
- React
- Vite
- Redux Toolkit
- React Router

### Server
- Node.js
- Express
- MongoDB
- Mongoose
- JWT Authentication
